# RV32I Core

A SystemVerilog implementation of a developing RV32I CPU core.

## Current Status

Implemented and unit tested:

- RV32I instruction field extraction
- 32 x 32-bit register file
- 32-bit ALU
- I-type immediate generation
- R-type and I-type ALU decoding
- Basic R/I control signals

The project is currently under development toward a complete single-cycle RV32I processor.

## Tools

- SystemVerilog
- Icarus Verilog
- GTKWave
